皆様お久しぶりです。また、くりすたのポートフォリオが生まれ変わりました！  
これまでに3回ポートフォリオを公開し、今回で4回目となりました。前回と比べてどのように変わったのかをお伝えできればと思います。

## 1. デザインの大幅な変更

前回のポートフォリオ(以降v3) では、TailwindCSSとshadcn/ui を導入し、決まったデザイントークンを持たないものになっていました。そのため、ページ間であまり共通したトークンが使われず見栄えがあまりよくない状況となっていました。  
今回は、自身がいつも愛用している「Catppuccin Theme」のデザイントークンをもとに、TailwindCSS × shadcn/ui の構成は変更しないまま実装することにしました。このデザイントークンは、個人的にかなり気に入っていてエディタだけでなく開発しているソフトウェアでもほぼ必ず実装するぐらいには愛用しています。  
また、[Inoriさん](https://lnkiai.com/) が開発されている[m3e-canvas](https://github.com/lnkiai/m3e-canvas) の実装を参考に、M3E(Material 3 Expressive)デザインのような丸いデザインを採用しました。  
フォントに関しては前々から使用したいと考えていた「[ナタデココゴシック](https://booth.pm/ja/items/8810868)」と、Zen 丸ゴシックを採用しました。

## 2. CMSの実装

v3の時では、Newsセクションはありましたがあまり使用することはありませんでした。というのも、いちいちMarkdownファイルを作成・変更する必要があり、手間がかかってしまったためです。  
そのため、今回はCMSを導入し、主にWorks・Blogs・Memosをウェブ上で管理できる仕組みを整備しました。このブログ自体もCMSから記述しています。

![CMSの画像](/pasted-image-1790421037398.png "CrystaworldのCMS")

実装してみて、実際にかなり便利だったのでこれからこちらもブログの方も動かしていこうと思います。ブログの種類としては、今のような雑多がメインとなる `#random`や、各言語ごとのタグがありますのでフィルタ機能と一緒に使ってみてください！

## 3. OGP 自動生成の実装

2つ目のCMSによるブログの投稿ができるようになったことを踏まえ、Blogs並びにMemosで[Satori](https://github.com/vercel/satori) によるOGP画像の自動生成機能も実装しました。  
これにより、QiitaやZennのようにブログのタイトルがわかるようになりました。

## 4. 技術スタックの変更

技術スタックもv3の時に比べて大幅に変更しています。v3では、ベースとしてNext.jsを採用していました。が、最近ではTanstack Routerを使うことが増えてきたため、Tanstack Router × React 19をベースとし、TailwindCSS v4 × shadcn/ui の構成に変更しました。Tanstack RouterではデフォルトでViteをサポートしているほか、Next.jsと同じようにお手軽にFile based Router(ファイルを配置することで自動的にページがルーティングされる)ができるので、開発体験がとても良いです。

## これまでのポートフォリオについて

これまでのポートフォリオもアーカイブとして残していますので是非ご覧ください！また、これを機に今までどのような技術を使っていたのか簡単に紹介します。

### Crystaworld v1

私がフロントエンドを書くきっかけとなったのがVue.jsです。当初からVueかReactかという選択肢がありましたが、JavaScript内でHTMLを扱うという考え方が当時の自分に全く刺さらず、HTMLの書き方とあまり大差がないVue.jsを勉強していました。なお、SPAで扱っていたので初期レンダリングに非常に時間がかかりました。

> [!NOTE]
> 現在では、このサイトはリポジトリ上及びサイト上からも削除してしまったため見ることはできません。

### Crystaworld v2

v2では、Vue.jsの派生となるNuxtを勉強していたため、Nuxtを採用しました。v2ではほとんどリンク集のような扱いになっているかと思います。一部はアカウント名が変わっていたり、アカウントを消したりしているので今は見つからないものがあるかもしれません。アーカイブしているので全く変更していない状態です。

https://v2.crystaworld.dev/

### Crystaworld v3

つい先日まで使用していたverのものです。v3からはVueから一転してReactをメインにしていたため、Next.jsを採用しました。また、これを機にドメインを変更し、現行の `.dev` ドメインにしました。

https://v3.crystaworld.dev/
